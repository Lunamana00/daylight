# Dailog Mac 바탕화면 달력 설치

[설치 파일 받기](https://github.com/Lunamana00/daylight/releases/download/v1.4.2-beta.1/Dailog-1.4.2-macos-universal.dmg) · [릴리스 페이지](https://github.com/Lunamana00/daylight/releases/tag/v1.4.2-beta.1) · [Dailog 웹](https://daylight-google.galaxycoreadvence.workers.dev)

macOS 26 이상에서 사용할 수 있습니다. Apple Silicon과 Intel용 앱이 함께 들어 있습니다. Xcode와 GitHub 계정은 필요 없습니다. Dailog에 초대된 Google 계정은 필요합니다.

## 설치하고 로그인하기

1. 위 링크에서 `Dailog-1.4.2-macos-universal.dmg`를 받습니다.
2. 앱이 실행 중이면 종료합니다. 설치 파일을 열고 **Dailog.app**을 **Applications** 폴더로 끌어 놓습니다. 이전 버전에서 업데이트할 때는 설치 후 응용 프로그램 폴더에 남은 **daylight.app**을 휴지통으로 옮깁니다.
3. Finder의 **응용 프로그램**에서 **Dailog**를 실행합니다. 설치 디스크 안에서 직접 실행하지 않습니다.
4. **Google로 로그인**을 누르고 Dailog에 초대된 계정으로 로그인합니다.
5. 로그인하면 바탕화면에 반투명 달력이 표시됩니다. 제목 표시줄과 Dock 아이콘은 없습니다. 메뉴 막대의 해 모양 아이콘으로 달력을 표시하거나 숨길 수 있습니다.

현재 파일은 **Apple 공증을 받지 않은 테스트 배포판**입니다. 개발자 확인 경고가 표시되면 공식 릴리스에서 받은 파일인지 확인한 뒤, **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 이 앱의 실행을 허용할 수 있습니다. 이 버튼은 앱을 한 번 실행하려고 한 뒤 나타납니다. [Apple의 실행 안내](https://support.apple.com/ko-kr/102445)를 참고하세요. 손상 또는 악성 소프트웨어 경고가 표시되면 실행하지 말고 오류 내용을 알려주세요.

## 바탕화면 달력 사용하기

기본 크기는 1,000×500입니다. 날짜 영역이나 아래쪽 이동 손잡이를 잡아 위치를 옮깁니다. 오른쪽 아래 크기 손잡이를 끌면 크기가 바뀝니다. 최소 크기는 720×360이며 위치와 크기를 기억합니다. 달력은 바탕화면에 남아 있고 일반 앱 창은 그 위에 표시됩니다. 손잡이에 초점을 둔 상태에서 방향키로도 이동하거나 크기를 조절할 수 있습니다.

오늘부터 4일을 표시하고, 오늘 칸을 넓게 보여줍니다. 시간표는 현재 한국 시간 부근에서 시작합니다. **지금**을 누르면 현재 시각으로 돌아옵니다. 아래 시간 버튼으로 앞뒤 시간대를 볼 수 있습니다.

할 일은 한 줄로 표시합니다. 긴 제목은 천천히 흘러가며, 포인터를 올리거나 **글자 흐름**을 누르면 멈춥니다. Mac의 **동작 줄이기** 설정도 적용합니다. 할 일 왼쪽 손잡이를 끌면 파란 삽입선이 나타납니다. 완료 항목은 아래에 유지됩니다. 바뀐 순서는 웹의 오늘 목록과 위젯에도 반영됩니다. 우클릭 메뉴에서도 순서를 바꿀 수 있습니다.

Google 일정을 옮기려면 달력 오른쪽 메뉴의 **Google 일정 이동 허용…**을 선택합니다. Google에서 수정 권한을 허용하고 연결할 캘린더를 선택합니다. 이후 일정을 다른 날짜나 시간으로 끌어 놓으면 Google에도 저장됩니다. 일정 길이는 그대로 유지되고, 반복 일정은 옮긴 회차 하나만 바뀝니다. 참석자가 있으면 Google에서 변경 알림을 보냅니다. 읽기 전용 캘린더는 옮길 수 없습니다.

## macOS 기본 위젯을 별도로 추가하기

바탕화면 달력은 앱을 실행하면 바로 표시됩니다. macOS 위젯 선택 목록에서도 별도 위젯을 추가할 수 있습니다. 기본 위젯에서는 내부 드래그와 제목 흐름을 지원하지 않습니다. 같은 위치에 겹치면 기존 기본 위젯을 우클릭하고 **위젯 제거**를 선택합니다.

1. 바탕화면의 빈 곳을 우클릭하고 **위젯 편집**을 엽니다.
2. **Dailog**를 검색합니다.
3. **Dailog 주간 달력**의 가장 큰 크기를 바탕화면에 추가하고 **완료**를 누릅니다. 기존 위젯은 우클릭한 뒤 크기를 바꿀 수 있습니다.

가장 큰 크기에서는 오늘부터 4일의 시간표를 표시합니다. 오늘 칸은 넓게 표시합니다. 시간이 있는 일정은 Google의 시작·종료 시간에 맞춰 배치합니다. 할 일과 종일 일정은 시간표 위에 표시합니다. 아래 시간 화살표로 다른 시간대를 볼 수 있습니다. 중간 크기와 큰 크기에서는 주간 날짜 줄과 선택한 날의 내용을 표시합니다. 날짜를 누르면 해당 날짜의 할 일과 Google 일정이 나옵니다. 하위 할 일도 지정한 날짜에만 표시합니다.

할 일 제목은 여러 줄로 표시합니다. 시간표에서 긴 일정 제목 위에 포인터를 두면 전체 제목을 볼 수 있습니다. 프로젝트와 상위 작업 이름은 제목 위에 표시하고, 같은 이름은 반복하지 않습니다. 공간이 부족하면 아래 페이지 버튼으로 나머지 항목을 볼 수 있습니다. 아래쪽 완료 수는 오늘의 전체 할 일을 기준으로 합니다. 완료 항목은 미완료 항목 아래에 표시합니다.

오늘 할 일의 체크박스로 완료 상태를 바꿀 수 있습니다. 다른 날짜의 할 일을 누르면 웹이 열립니다. 새로고침 버튼은 할 일과 연결된 Google 캘린더를 동기화합니다. 위젯의 본문을 누르면 Dailog 웹이 열립니다. 확장 버튼을 누르면 바탕화면 달력이 표시됩니다. 할 일 순서는 웹의 **내 할 일**에서 손잡이를 끌거나 손잡이에 포커스를 둔 상태에서 방향키로 바꿉니다. 바뀐 순서는 위젯에도 반영됩니다.

Google 일정은 웹의 **설정 → Google 캘린더 선택**에서 연결합니다. 위젯을 우클릭하고 **위젯 편집**을 선택하면 Google 일정 표시를 켜거나 끌 수 있습니다.

## 위젯이 보이지 않을 때

- 바탕화면 달력이 보이지 않으면 응용 프로그램 폴더에서 **Dailog**를 실행합니다. 메뉴 막대의 해 모양 아이콘에서 **바탕화면 달력 표시**를 선택할 수도 있습니다.
- 기본 위젯을 추가하려면 앱에서 로그인을 완료한 뒤 위젯 편집을 다시 엽니다.
- 내용이 비어 있으면 달력 아래쪽의 새로고침 버튼이나 메뉴 막대의 **동기화**를 누릅니다.
- 초대되지 않은 계정이라는 메시지가 나오면 Dailog 관리자에게 해당 Google 이메일의 초대를 요청합니다.
- 이전 개발용 앱에서 업데이트했다면 Google 로그인을 한 번 다시 진행합니다. 웹에 저장된 할 일과 프로젝트는 유지됩니다.

설치 파일에는 다른 사용자의 할 일, 캘린더 기록, 로그인 정보가 포함되지 않습니다. 로그인한 본인의 데이터가 서버에서 동기화됩니다.

다른 사람의 Mac에서의 최초 설치는 확인하지 않았습니다.
