# daylight work records

Automatic collection is paused. Do not read conversations, create a collector connection, import outcomes, or schedule collection for this skill. The collector endpoint returns HTTP 410.

The user enters records and selects PDF or image outputs in **작업물**. A project can connect a private GitHub repository. **GitHub에 저장** saves a version of a manual record and its outputs. Existing records are not transferred automatically.

See [work records](../../docs/work-log.md) for connection and storage details. Keep GitHub tokens out of chat, command arguments, logs, and Git.
